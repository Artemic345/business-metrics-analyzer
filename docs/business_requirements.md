# Бизнес-требования к приложению Business Metrics Analyzer

## 1. Назначение приложения
Приложение Business Metrics Analyzer предназначено для учебного 
анализа бизнес-метрик предприятия.

## 2. Бизнес-задача
Приложение предназначено для расчёта и анализа основных 
бизнес-показателей: выручки, затрат и рентабельности.

## 3. Целевая аудитория
Студенты, аналитики, малые предприятия, желающие оценить 
прибыльность своей деятельности.

## 4. Функциональные требования
- Расчёт средней выручки за период.
- Расчёт рентабельности по формуле: (выручка − затраты) / выручка × 100%.
- Обработка случая нулевой выручки (возврат 0).
- Вывод результатов в консоль.

## 5. Нефункциональные требования
- Язык программирования: Python 3.10+.
- Кроссплатформенность (Windows, Linux, macOS).
- Простота запуска: одна команда `python main.py`.

## 6. Используемые технологии
- Python 3.10+
- pandas
- matplotlib

## 7. Ограничения
- Приложение учебное, не предназначено для коммерческого 
  использования в production.
- Нет графического интерфейса (только консоль).
